# 映流 · DSH 视频工作台

`dsh-video-studio` 0.2.0 是 DSH Desktop 的独立插件。用户可以在已有会话中讨论视频，让当前会话模型调用视频工具完成规范化分镜、前端源码、检查和导出；需要细看时，从工具卡片打开工作台，查看镜头、实际帧和音轨，也可继续手动编辑。

## 安装与环境

在 DSH 的「插件管理 → 添加插件」中输入发行 `.tgz` 的绝对路径，安装完成后启用。适配 DSH `0.2.0-rc.2`，以 macOS Desktop 为主要验收平台。

插件包含独立 LiteGraph 客户端和 Playwright 驱动，无需安装 ComfyUI。渲染使用本机 Chrome/Chromium、FFmpeg、ffprobe；在工作台「环境」页检测或配置执行文件路径。会话制作使用当前会话的模型；独立工作台生成复用 DSH 已配置模型。

新项目默认保存到 `~/Documents/DSHVideoProjects`。组合包配置 `baseDirectory` 可以修改位置。开发验收使用独立项目目录和宿主 profile。旧版图片/文字、无声项目可以直接打开，新增字段为可选字段，仍使用 schemaVersion 1。

## 在会话中制作

启用插件后，在已有 DSH 会话中上传图片、文字或音频并描述目标，例如：

> 用这些图片做一部约 30 秒的中文介绍视频，竖屏 4:5、1080p、30 FPS。先整理五个镜头，再写前端动画代码。保留镜头的可编辑文字和图片参数，导出前检查实际帧。

模型通过 `video_project` 创建或绑定工程，`video_update` 写入素材、分镜与源码，`video_inspect` 查看制作要求、源码和实际帧，`video_render` 发起检查或导出，`video_audio` 导入、绑定或生成配音。耗时任务进入 DSH Jobs，模型可用 `job_output` 获取结果、`job_kill` 取消。工具不另起一个聊天模型。

会话和工程的关系会保存：一个会话可绑定多个工程并指定当前工程，工具省略 projectId 时使用该会话当前工程；多个会话可显式绑定同一个工程。工具返回稳定工程 ID、版本和镜头数据，模型可以先读取用户手动编辑的当前版本，再局部修改。工具卡片可直接定位到工作台中的工程、镜头及全片帧；工作台也提供绑定当前会话和返回关联会话入口。

建议对话改片时明确范围，例如“只改第三镜头的标题和运动，其余镜头保持不变”。模型先读取工程，将 revision 放入 expectedRevision，并提交 shotPatches 或选定镜头 sources。完整接口见 [docs/API.md](docs/API.md)。

## 工作台编辑

1. 新建或打开工程。上传 PNG/JPEG/WebP，粘贴文字或导入 TXT/Markdown。音频支持 WAV、MP3、M4A、AAC、FLAC、OGG；视频上传仍未开放。
2. 画布支持平移、缩放、全图概览、100% 显示、聚焦选中节点和扩大编辑区。资产连接镜头表示使用或参考；镜头依次连到成片节点构成主链。底部镜头条编辑同一套顺序。画布的位置用于整理，视频里的图片位置通过镜头参数调整。
3. 输出设置提供 16:9、9:16、1:1、4:3、3:4、4:5、21:9 及自定义比例，480p、720p、1080p、1440p、4K 和自定义尺寸。帧率包括 24、25、30、50、60、24000/1001、30000/1001、60000/1001，也可输入自定义分数。切换帧率按秒换算镜头，避免反复切换造成时长累计漂移。质量档为标准、高质量和更小文件，对应 H.264 CRF 18、16、23。
4. 预览运行实际 HTML/CSS/JavaScript 与项目资产。支持播放、暂停、逐帧前后、输入全片帧、镜头定位、局部帧/秒显示、关键帧缩略图、大预览及实际帧 PNG 导出。含音轨时以音频播放时间驱动画面；拖动和导出仍依据统一帧契约。
5. 镜头属性可以编辑顺序、时长、文字、图片、位置、缩放、颜色、动作参数和旁白。高级「源码」页编辑 HTML/CSS/JS；保存后检查，运行错误可恢复上个可用源码。独立工作台仍提供模型生成和自然语言改片。
6. 在声音面板导入配音、背景音乐或音效，绑定到镜头或全片，设置开始时间、裁剪、音量、淡入淡出和循环。配音按实际选中音频长度与偏移计算所需画面时长；默认只在必要时延长镜头。锁定时长后若旁白超时会显示差额，用户可缩短、裁剪或解除锁定。重新生成同一镜头配音会替换其原配音片段，旧音频资产保留可复用。
7. 导出使用任务启动时的项目和源码快照，输出 H.264 MP4；启用混音时加入 AAC 48 kHz 双声道。完成后在工作台播放结果或打开目录。

页面自动保存项目。离开页面、重启 DSH 后可以继续编辑；画布编辑支持撤销/重做，源码备份与音频资产单独保留。

## 配音提供方

环境页可启用 macOS 本地 `say`，选择已安装音色，例如中文 `Tingting`，调整语速。默认不启用自动配音，明确启用后才生成。

也可配置提供 `/audio/speech` 的 HTTP 兼容端点、模型、音色与语速。Key 只保存到 DSH 凭据服务，不写入工程、配置 JSON 或工具返回；清空 Key 会删除该凭据。插件不默认选择远程配音厂商，也不复用聊天供应商的 Key。兼容接口的本地测试不代表某一真实云端配音服务已经验收。

## 项目与扩展

`project.json` 保存分镜、参数、图文/音频资产引用、画布布局、声音片段和关联 session ID；`assets/` 保存媒体；`shots/<id>/` 保存可编辑源码。`runtime/` 与运行页由插件生成；`exports/<id>/` 保存成片、输入快照与媒体检查。工程目录可以搬运，关联 session ID 只在对应 DSH 安装中有效。

分镜负责内容编排，源码负责具体画面。模型可以编写新布局和动画；已暴露参数通过 ctx.params 读取。自定义源码继续由源码或自然语言编辑，不自动反向解析为可视图层。

图编辑器、场景生成器、帧渲染器和导出器保留替换接口。声音采用类型资产、以秒为单位的音频片段、提供方适配和独立混音模块。当前不建设节点市场、云端队列、多人协作、视频输入或完整图层关键帧编辑器。

## 开发与验收

```sh
npm ci --legacy-peer-deps --ignore-scripts
npm run typecheck
npm test
npm run build
npm pack --pack-destination artifacts
```

构建需要 Node 22.18+ 或 24+。同版本 DSH peer packages 由宿主提供；本机可使用 `node scripts/prepare-local.mjs` 链接已有开发依赖，发行锁文件不含本机路径。

`npm run preview` 使用官方 DSH 运行库和独立 profile，默认端口 19405。模拟供应商仅用于可重复的工具与业务测试，不进入发行包。`scripts/verify-client-v2.mjs` 检查真实 UI 和 DPR；会话工具验收使用真实 DSH agent loop 加本地固定模型响应。声音检查包括真实系统配音、FFmpeg 混音和媒体回读。记录明确区分模拟模型、本地实际媒体、原生 UI、远程提供方及完整人工观看。

V1 验收文件保存在 `artifacts/verification/`，V0.2 记录保存在 `artifacts/verification/v0.2/`。许可与来源见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
