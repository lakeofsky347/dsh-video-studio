## 使用与验证边界

本轮安装包为 `artifacts/dsh-video-studio-0.6.0.tgz`，可按 README 的 DSH 安装方式使用。插件不依赖独立应用，不要求修改 DSH 内核或运行公共常驻网关。先配置媒体连接、模型和角色，再使用工作台或 `video_media`。

本轮 DSH 集成测试使用真实插件代码与受控宿主接口；未新增真实 DSH Desktop 原生窗口、禁用/重启、Windows/macOS 安装验收。跳过的两项测试依赖 macOS `/usr/bin/say`；既有历史验收保持其原版本范围。

真实供应商协议、生成质量、费用和性能收益待用户配置后分别验证。生视频仅承诺实现 [网关 v1](media-gateway-v1/README.md) 的服务；厂商原生协议需追加适配器。金额上限缺少全流程可靠报价时在调用模型前暂停，未知费用不记为零。

更多配置、恢复、取消、上传授权与工程 v2 说明见 [多模态制作](MULTIMODAL.md)。本仓不承诺与独立应用完整工程包互通；完整插件工程迁移仍保留 `.studio/` 历史目录。
