# README 配图来源

这组图片于 2026 年 10 月 7 日从映流 0.4.0 的独立 DSH Web 测试环境截取，使用与插件工作台相同的客户端界面。截图直接取自页面或对应控件区域，未修改界面内容或后期合成。

演示工程「城市漫步 · 影片示例」包含三个镜头，规格为 1280 × 720、24 FPS、12 秒。文案、前端画面和提示音均为文档专门制作的本地示例。截图过程没有调用真实模型或语音服务，也没有执行成片导出。工作台中的预览运行了示例工程的实际源码。

| 文件 | 展示内容 |
| --- | --- |
| `home.png` | 首次打开的影片首页，新建、打开工程和会话筛选入口 |
| `workbench.png` | 分镜画布、镜头属性、顺序和第 36 帧的实际预览 |
| `environment.png` | 本地浏览器、FFmpeg 和 ffprobe 的环境检查 |
| `audio.png` | 本地合成音效的试听、时间、裁剪、音量与淡入淡出参数 |
| `source.png` | 当前镜头的前端源码与保存入口 |
| `export.png` | 输出规格设置，未展示已导出成片 |
| `session.png` | 专用演示会话的关联选择 |

界面截图用于解释操作位置。演示数据和固定响应模型名称不表示真实云端模型的制作质量、服务可用性或配音效果。
